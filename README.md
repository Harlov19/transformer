# Transformer from scratch (PyTorch)

A step-by-step implementation of the Transformer architecture introduced in
"Attention Is All You Need."

## Project layout

```text
model/
  attention.py
  config.py
  decoder.py
  encoder.py
  layers.py
  masks.py
  transformer.py
data.py
train.py
evaluate.py
infer.py
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```
